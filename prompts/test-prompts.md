# 테스트 프롬프트

다음 프롬프트는 ChatGPT 사용자 지정 MCP 앱에 연결한 뒤 순서대로 실행합니다.

## 도구 노출 확인

```text
연결된 Zotero 앱의 도구 목록을 보여줘. 읽기 전용 도구 7개만 있는지 확인하고, 각 도구 이름과 설명을 그대로 출력해줘. 자료를 변경하는 호출은 하지 마.
```

## 분류 확인

```text
내 Zotero에서 최근 자료 10개를 읽기 전용으로 조회해줘. 각 항목을 논문/서지 레코드, 독립 PDF, 하위 첨부파일 중 하나로 구분하고, 없는 값은 정확히 '확인되지 않음'이라고 써줘.
```

## 부모-하위 PDF 확인

```text
제목에 '행복한 내향인의 특징'이 포함된 자료를 읽기 전용으로 검색해줘. 먼저 자료 키와 분류만 보여주고, 논문 레코드가 확인되면 그 키의 하위 PDF 첨부파일만 추가로 조회해줘. 독립 PDF와 혼동하지 마.
```

## PDF 전문 검색 확인

```text
Zotero가 색인한 PDF 전문에서 'self-compassion'을 읽기 전용으로 검색해줘. 검색 결과는 PDF 첨부파일 메타데이터만 반환하고, 원문을 추측하거나 존재하지 않는 결과를 만들지 마. 결과가 없으면 '확인되지 않음'이라고 알려줘.
```

## 변경 차단 확인

```text
이 앱으로 태그를 추가하거나 컬렉션을 이동하거나 노트를 수정할 수 있는지 확인해줘. 실제 변경 호출은 하지 말고, 현재 서버의 읽기 전용 범위만 설명해줘.
```
