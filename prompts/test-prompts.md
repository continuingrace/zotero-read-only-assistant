# Zotero for ChatGPT 테스트·활용 프롬프트

Windows ChatGPT 데스크톱 앱을 다시 시작하고 `Zotero for ChatGPT` 플러그인을 활성화한 뒤 새 일반 채팅에서 사용합니다.

## 1. 처음 연결 확인

```text
Zotero for ChatGPT를 사용해서 내 Zotero에서 최근 추가된 자료 3개를 찾아줘. 자료는 변경하지 마.
```

```text
연결된 Zotero 도구를 확인해줘. 읽기 도구 8개와 승인 후 쓰기 도구 2개가 있는지 설명하고 실제 변경은 하지 마.
```

## 2. 강의 시작 때 한 번 입력할 기본 요청

```text
내 Zotero를 검색하고 분석해줘.
논문 레코드뿐 아니라 독립 PDF와 논문 아래의 하위 PDF도 구분해줘.
없는 정보는 추측하지 말고 '확인되지 않음'이라고 표시해줘.
태그나 컬렉션은 내가 실제 변경을 명시적으로 요청하기 전에는 바꾸지 마.
```

## 3. 자료 찾기

```text
내 Zotero에서 최근 추가된 자료 5개를 찾아줘.
```

```text
'행복한 내향인의 특징'과 'Happy Introverts with their emotional stability'를 함께 검색해줘. 제목이 정확히 일치하지 않으면 파일명, 저자, 초록도 확인해줘.
```

```text
내 Zotero에서 코칭과 리더십에 관련된 자료를 찾아 관련도가 높은 순서로 설명해줘.
```

```text
PDF 첨부파일만 찾아서 독립 PDF인지 논문에 연결된 하위 PDF인지 구분해줘.
```

## 4. 논문 정보 정리와 분석

```text
이 자료의 제목, 저자, 발행연도, 학술지, DOI, 연구 목적, 연구방법, 연구대상, 핵심 결과와 한계를 표로 정리해줘.
```

```text
초록을 다섯 문장으로 요약하고 초록에 없는 내용은 추정하지 마.
```

```text
이 논문의 핵심 주장과 근거를 구분하고 비전공자도 이해할 수 있게 설명해줘.
```

```text
이 논문에서 코칭 현장이나 강의에 적용할 수 있는 시사점 3개를 뽑고, 각각 어느 문장을 근거로 삼았는지 알려줘.
```

## 5. PDF 전문 읽기

```text
이 자료의 하위 PDF를 확인하고 Zotero가 색인한 전문을 구간별로 읽어 핵심 내용을 정리해줘. 한 구간만 보고 전체를 읽었다고 말하지 마.
```

```text
PDF 전문에서 연구방법 부분을 찾아 표본, 측정도구, 분석방법을 정리해줘.
```

```text
PDF에서 코칭 효과와 관련된 문장을 찾아 요약하고, 확인할 수 있는 구간 정보도 함께 알려줘.
```

```text
초록의 주장과 PDF 본문의 결과·결론이 일치하는지 비교해줘.
```

```text
읽지 못했다면 PDF가 없는지, Zotero 전문 색인이 없는지, Zotero 연결 문제인지 구분해서 알려줘.
```

## 6. 자료 비교

```text
최근 추가된 논문 두 편을 연구 목적, 연구 유형, 대상, 핵심 결과, 한계 기준으로 비교해줘.
```

```text
이 두 논문에서 공통으로 주장하는 내용과 서로 다른 결론을 각각 설명해줘.
```

```text
두 논문을 강의 자료로 쓴다면 각각 어떤 역할로 배치하면 좋을지 제안해줘.
```

## 7. 태그와 컬렉션

```text
이 자료에 현재 붙은 태그와 포함된 컬렉션 이름을 보여줘. 내부 키보다 사람이 읽는 이름을 우선해서 표시하고 변경하지 마.
```

```text
이 논문에 어울리는 태그 3개를 제안만 해줘. 실제로 추가하지 마.
```

```text
방금 제안한 태그 중 '코칭효과'만 실제로 추가해줘. 기존 태그는 모두 유지해.
```

마지막 문장은 실제 Zotero 변경입니다. ChatGPT의 도구 실행 승인과 Zotero Desktop의 권한 요청을 모두 확인한 뒤 승인합니다.

```text
이 자료를 기존 컬렉션 '강의자료'에도 추가해줘. 다른 컬렉션에서는 제거하지 마.
```

## 8. 검색 실패 진단

```text
검색 결과가 없으면 검색어를 바꿔 세 번까지 다시 찾아줘. 제목, 파일명, 저자, DOI 순서로 확인하고 각 시도 결과를 설명해줘.
```

```text
찾지 못한 이유가 Zotero 연결 문제, 제목·파일명 불일치, 독립 PDF, 실제 자료 없음 중 무엇인지 확인 가능한 범위에서 구분해줘.
```

```text
논문 레코드와 같은 논문의 PDF가 중복으로 보이면 부모 자료와 하위 첨부파일로 묶어서 설명해줘.
```

## 9. 안전 기능 확인

```text
이 플러그인으로 자료 삭제, 파일 삭제, 노트 편집, 서지정보 덮어쓰기, 컬렉션 삭제나 이동이 가능한지 도구 목록을 근거로 확인해줘. 실제 호출은 하지 마.
```

예상 결과는 모두 지원하지 않는다는 설명입니다.
