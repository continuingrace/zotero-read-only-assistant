# GitHub에서 참가자에게 배포하는 방법

## 관리자

1. GitHub 저장소의 초록색 `Code` 버튼을 누릅니다.
2. `Download ZIP`을 누릅니다.
3. 내려받은 ZIP 파일을 참가자에게 보냅니다.
4. 참가자에게 Zotero Desktop도 설치하도록 안내합니다.

참가자에게 GitHub 계정이나 저장소 수정 권한을 줄 필요는 없습니다. 참가자는 ZIP 파일만 내려받아 사용합니다.

## 참가자

1. ZIP 파일을 내려받습니다.
2. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 `속성 → 차단 해제`가 보이면 체크하고 적용합니다.
3. `압축 풀기`를 누릅니다.
4. Zotero Desktop을 실행합니다.
5. 압축을 푼 폴더에서 `participant\Start-Participant.vbs`를 더블클릭합니다.
6. `Setup and Start` 버튼을 누릅니다.
7. 브라우저에 열린 Zotero 읽기 도우미에서 검색합니다.

## 주의

- 참가자 컴퓨터의 Zotero 자료는 참가자 컴퓨터에서만 읽습니다.
- 이 프로그램은 Zotero에 자료를 추가하거나 수정하거나 삭제하지 않습니다.
- 프로그램이 “Zotero에 연결할 수 없습니다”라고 하면 Zotero가 실행 중인지, 로컬 API 허용이 켜져 있는지 확인합니다.
- Python 설치가 필요한 경우에는 관리자가 한 번 설치를 도와줍니다. 이후에는 참가자가 명령어를 입력하지 않습니다.
