# GitHub에서 참가자에게 배포하는 방법

## 관리자

1. GitHub 저장소 오른쪽의 `Releases`를 누릅니다.
2. 최신 버전의 `Zotero-Read-Only-Assistant.exe`를 내려받습니다.
3. 실행 파일 또는 Releases 주소를 참가자에게 보냅니다.
4. 참가자에게 Zotero Desktop도 설치하도록 안내합니다.

참가자에게 GitHub 계정이나 저장소 수정 권한을 줄 필요는 없습니다. Python도 설치할 필요가 없습니다.

## 참가자

1. `Zotero-Read-Only-Assistant.exe`를 내려받습니다.
2. Zotero Desktop을 실행합니다.
3. 실행 파일을 더블클릭합니다.
4. Windows 보호 화면이 나오면 파일 이름과 배포처를 확인한 뒤 `추가 정보 → 실행`을 누릅니다.
5. 자동으로 열린 브라우저의 Zotero 읽기 도우미에서 검색합니다.
6. 사용을 마치면 브라우저 화면의 `프로그램 종료`를 누릅니다.

## 주의

- 참가자 컴퓨터의 Zotero 자료는 참가자 컴퓨터에서만 읽습니다.
- 이 프로그램은 Zotero에 자료를 추가하거나 수정하거나 삭제하지 않습니다.
- 프로그램이 “Zotero에 연결할 수 없습니다”라고 하면 Zotero가 실행 중인지, 로컬 API 허용이 켜져 있는지 확인합니다.
- Python, 터미널, PowerShell, HTTPS 주소, 인증 토큰을 입력할 필요가 없습니다.
- 실행 파일은 현재 코드 서명 인증서가 없으므로 Windows가 처음 한 번 보호 안내를 표시할 수 있습니다.
