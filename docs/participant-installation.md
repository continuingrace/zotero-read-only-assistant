# 참가자용 설치 안내

이 설치는 Windows용 ChatGPT 데스크톱 앱의 일반 채팅에서 내 Zotero 자료를 찾고 분석하기 위한 것입니다. 터미널과 Python은 필요하지 않습니다.

## 준비물

- 개인 Windows PC
- [Zotero Desktop](https://www.zotero.org/download/)
- Windows용 ChatGPT 데스크톱 앱
- `Zotero-for-ChatGPT-Windows.zip`

각 참가자는 자기 PC와 자기 ChatGPT 계정을 사용합니다. 관리자에게 HTTPS 주소, 포트 번호, 인증 토큰을 받아 적는 과정은 없습니다.

## 처음 한 번 설치

1. Zotero Desktop을 설치하고 엽니다.
2. Zotero의 `편집 → 설정 → 고급`에서 `이 컴퓨터의 다른 애플리케이션이 Zotero와 통신하도록 허용`을 켭니다. macOS가 아니라 Windows 기준이며 Zotero 버전에 따라 문구 위치가 조금 다를 수 있습니다.
3. `Zotero-for-ChatGPT-Windows.zip`을 마우스 오른쪽 버튼으로 눌러 `모두 압축 풀기`를 선택합니다.
4. 압축을 푼 폴더의 `Install-Zotero-for-ChatGPT.cmd`를 더블클릭합니다. 검은 창이 잠깐 나타날 수 있지만 명령을 입력하지 않습니다.
5. `설치가 완료되었습니다` 안내가 나오면 ChatGPT 앱을 완전히 종료합니다. 창만 닫지 말고 작업표시줄 알림 영역에서도 종료한 다음 다시 엽니다.
6. ChatGPT에서 `설정 → 플러그인`을 열고 `Personal` 목록의 `Zotero for ChatGPT`를 설치하거나 활성화합니다.
7. 새 일반 채팅을 엽니다. Codex Work를 열 필요가 없습니다.

## 첫 확인 문장

```text
Zotero for ChatGPT를 사용해서 내 Zotero에서 최근 추가된 자료 3개를 찾아줘. 자료는 변경하지 마.
```

자료 제목이 나오면 연결된 것입니다. 그다음 이렇게 시험합니다.

```text
첫 번째 자료의 제목, 저자, 연도, 초록을 정리하고 PDF가 있으면 전문 검색 가능 여부도 확인해줘. 없는 정보는 '확인되지 않음'이라고 써줘.
```

## 평소 사용법

ChatGPT와 Zotero를 먼저 실행한 뒤 일반 채팅에서 자연어로 요청하면 됩니다.

```text
내 Zotero에서 코칭과 리더십에 관한 논문을 찾아 핵심 주장과 연구방법을 비교해줘.
```

```text
'행복한 내향인의 특징'을 제목, 파일명, 저자, 초록에서 찾아줘. 논문 레코드와 독립 PDF와 하위 PDF를 구분해줘.
```

```text
이 자료의 PDF 전문에서 연구방법 부분을 찾아 비전공자도 이해할 수 있게 설명해줘.
```

## 태그와 컬렉션 변경

단순 제안은 Zotero를 바꾸지 않습니다.

```text
이 논문에 어울리는 태그 3개를 제안만 해줘. 아직 추가하지 마.
```

실제로 태그를 추가하면 ChatGPT가 도구 실행 승인을 묻고 Zotero도 쓰기 권한을 묻습니다. 두 내용을 확인한 뒤 승인해야 변경됩니다.

```text
방금 제안한 태그 중 '코칭효과'만 실제로 추가해줘. 기존 태그는 유지해.
```

이 플러그인은 자료 삭제, 파일 삭제, 노트 편집, 서지정보 덮어쓰기, 컬렉션 생성·삭제·이동을 지원하지 않습니다.

## 안 될 때

- `Zotero에 연결할 수 없음`: Zotero Desktop이 실행 중인지와 로컬 API 허용 설정을 확인합니다.
- 플러그인이 목록에 없음: ChatGPT를 완전히 종료했다가 다시 열고 `설정 → 플러그인 → Personal`을 확인합니다.
- PDF를 읽지 못함: PDF가 첨부되어 있는지, Zotero에서 텍스트 색인이 되었는지 확인합니다. 스캔 이미지 PDF는 OCR 전에는 전문이 없을 수 있습니다.
- 실행 파일이 열리지 않음: ZIP 안에서 바로 실행하지 말고 먼저 압축을 풀며, 파일 `속성 → 차단 해제`가 보이면 적용합니다.
- 태그 변경 승인이 안 뜸: Zotero 창이 다른 창 뒤에 숨어 있는지 확인합니다.

문제가 계속되면 설치 파일을 반복 실행하기보다 오류 화면과 ChatGPT 플러그인 목록 화면을 관리자에게 보냅니다.

## 개인정보 안내

연결 자체는 내 PC 안에서 `localhost`로만 이루어집니다. 다만 ChatGPT가 논문을 요약하거나 비교하려면 선택된 제목·초록·PDF 텍스트가 OpenAI 서비스로 전송될 수 있습니다. 민감하거나 비공개인 논문·인터뷰·연구자료는 소속기관의 정책과 본인 계정의 데이터 설정을 먼저 확인하세요.
