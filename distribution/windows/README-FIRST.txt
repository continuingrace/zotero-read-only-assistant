Zotero for ChatGPT 설치

1. 이 ZIP 파일을 먼저 완전히 압축 해제합니다.
2. Zotero Desktop을 실행합니다.
3. Install-Zotero-for-ChatGPT.cmd를 더블클릭합니다.
4. 설치 완료 창을 확인합니다.
5. ChatGPT 데스크톱 앱을 완전히 종료했다가 다시 엽니다.
6. 플러그인 > Personal에서 Zotero for ChatGPT를 설치합니다.
7. 새 일반 Chat에서 다음과 같이 입력합니다.

내 Zotero에서 최근 추가된 자료 3개를 찾아줘. 아무것도 변경하지 마.

Python, 터미널, API Key, HTTPS 주소는 필요하지 않습니다.
Source code ZIP과 이전 EXE 설치기는 사용하지 마세요.
검은 창이 잠깐 나타날 수 있지만 명령을 입력할 필요는 없습니다.
